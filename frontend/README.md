# TraVerse Frontend\n\nReact + TypeScript + Vite frontend for the TraVerse monorepo.\n\n## Architecture\n\nThe frontend is organized by responsibility:\n\n- `src/app` — application bootstrap, routing, providers, and guards.\n- `src/api` — backend transport and domain API modules.\n- `src/features` — domain-oriented UI and business workflows.\n- `src/layouts` — page-level layout shells.\n- `src/components` — reusable UI components.\n- `src/hooks` — reusable React hooks.\n- `src/lib` — framework-independent utilities.\n- `src/routes` — route-level composition.\n- `src/types` — shared TypeScript contracts.\n- `src/styles` — global styling.\n\n## Setup\n\nRequirements: Node.js 20.19+.\n\n```powershell\ncd frontend\nnpm install\nnpm run build\nnpm run test\nnpm run dev\n```\n\nThe browser application runs on `http://localhost:5173`.\n\n## Environment\n\nOnly browser-safe values may use the `VITE_` prefix. Never put API keys, database credentials, JWT signing secrets, or other private values in frontend environment variables.\n
